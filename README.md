# ☕ Responsive Cafe Menu

A clean, responsive web application designed for a cafe menu, built with **HTML5** and **CSS3**. This project demonstrates fundamental web development techniques including modern typography, custom styling, responsive spacing, and semantic HTML layout.

---

## 🚀 Features

- **Semantic HTML5 Structure:** Structured cleanly using semantic elements like `<header>`, `<main>`, `<section>`, `<article>`, and `<footer>`.
- **Responsive Layout:** Designed to scale dynamically across different screen sizes.
- **Custom CSS Styling:** Incorporates custom background imagery, typography, margins, hover effects, and styled horizontal rules.
- **Accessible Design:** Features descriptive `alt` tags on image elements and structured headings for screen-reader accessibility.

---

## 🛠️ Tech Stack

- **HTML5** — Document structure and markup
- **CSS3** — Styling, layout, and visual presentation
